# Kshetrajna Glossary

| Term | Meaning |
|---|---|
| EC | Electrical conductivity input used by the project soil/fertility system. |
| NPK | Nitrogen, phosphorus, potassium inference outputs. |
| LoRa | Long-range field telemetry radio in the architecture. |
| BLE | Bluetooth Low Energy for local Android/device communication. |
| ESP32 | Microcontroller platform for Kshetrajna nodes. |
| ACS712 | Current sensor identified in the safety architecture. |
| DS18B20 | Soil-temperature sensor identified in the architecture. |
| pH | Soil acidity/alkalinity input; current flow includes manual/app-assisted entry. |
| VPD | Vapor pressure deficit, identified as a decision-engine indicator. |
| Hysteresis | Decision technique identified to avoid unstable switching. |
| Lockout | State preventing an operation because of safety/decision logic. |
| Sync | Transfer/reconciliation of local data with backend/device systems. |
| Inferred | Derived/model output rather than direct sensor/lab measurement. |

# Kshetrajna Android App

Offline-first Android application for the Kshetrajna Smart Soil Intelligence & Safe Drip System.

Read first: `AGENTS.md`, then the relevant files in `docs/`.

This app provides soil telemetry, manual pH, fertility/NPK inference, weather context, irrigation state, alerts, BLE interaction, and backend synchronization.

**Important:** API endpoints, BLE UUIDs/packets, calibration constants, crop thresholds, NPK equations, and exact safety thresholds are `TBD` unless separately approved. Never invent them.
